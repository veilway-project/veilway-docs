# مستندات Veilway

کد منبع سایت مستندات [Veilway](https://github.com/veilway-project/veilway)، یک پلتفرم پروکسی و VPN که در حال ساخت است. سایت به دو زبان انگلیسی و فارسی نوشته می‌شود.

## وضعیت

این فقط یک اسکلت است. هر صفحه فعلا خالی است و فقط می‌گوید چه چیزی قرار است در آن مستند شود. هیچ چیز در اینجا هنوز نرم‌افزار منتشرشده‌ای را توصیف نمی‌کند.

یک کلاینت دسکتاپ ویندوز در کد فعلی وجود دارد. پنل، کلاینت‌های چندسکویی، کلاینت اندروید، ترنسپورت‌های جدید و لایه مبهم‌سازی هنوز ساخته نشده‌اند. لایه مبهم‌سازی وقتی منتشر شود آزمایشی خواهد بود و بازبینی بیرونی نخواهد داشت.

## ساختار

| مسیر | محتوا |
|---|---|
| `src/content/docs/` | صفحه‌های انگلیسی |
| `src/content/docs/fa/` | صفحه‌های فارسی، با همان نام فایل |
| `astro.config.mjs` | تنظیمات سایت، زبان‌ها و نوار کناری |

سایت با [Starlight](https://starlight.astro.build) و قالب پیش‌فرض آن ساخته می‌شود.

## ساخت

به Node.js نسخه 22.12 یا جدیدتر نیاز دارد.

</div>

```
npm install
npm run dev
npm run build
```

<div dir="rtl">

دستور `npm run dev` سایت را روی سیستم خودتان اجرا می‌کند. دستور `npm run build` سایت ایستا را در پوشه `dist/` می‌سازد.

## مشارکت

هر صفحه را در یک تغییر و در هر دو زبان اضافه یا ویرایش کنید. مثال‌ها فقط باید از نام‌ها و آدرس‌های نمونه استفاده کنند (`example.com`، `192.0.2.0/24`) و هرگز سرور یا کلید واقعی در آن‌ها نباشد.

Veilway یک پلتفرم پروکسی و VPN است برای کسانی که پشت شبکه‌هایی زندگی می‌کنند که اینترنت را مسدود یا زیر نظر دارند. سه بخش دارد که با هم کار می‌کنند:

- **نود**، یک برنامهٔ Rust که روی سرور شما اجرا می‌شود. اتصال دستگاه‌ها را می‌پذیرد، قواعد مسیریابی شما را اعمال می‌کند، و ترافیک را از طریق خروجی‌هایی که تنظیم کرده‌اید بیرون می‌فرستد.
- **پنل**، یک صفحهٔ وب برای اپراتور نود. کاربران، ورودی‌ها، خروجی‌ها، مسیریابی و اشتراک‌ها را مدیریت می‌کند.
- **کلاینت‌ها**، برنامه‌هایی که مردم روی دستگاه‌هایشان استفاده می‌کنند: یک برنامهٔ دسکتاپ برای لینوکس، macOS و ویندوز، و یک برنامهٔ اندروید.

نسخهٔ فعلی، آلفای `v0.2.4-alpha` است. زنجیرهٔ پراکسی برای اتصال‌های بیرونی و پیوندهای نود دارد، و پنل آن می‌تواند نود را هم مثل خودش به‌روز کند. تازه‌های v0.2.0: HTTP/2 روی ترنسپورت‌های جریانی، تونل از راه پیوند نودها، بسته‌های آفلاین، پیوندهای Xray در برنامهٔ دسکتاپ، رله برای هر کاربر و هر گروه، و حالت سایت قرضی که قابلیتی آلفا و به‌طور پیش‌فرض خاموش است. [نسخهٔ آلفا](./alpha/) می‌گوید چه چیزی در آن هست، هر بخش کجاست و محدودیت‌های شناخته‌شده‌اش چیست. [راهنمای نصب](./getting-started/) نود و پنل را توضیح می‌دهد. [راهنمای کلاینت](./manuals/client/) برنامهٔ دسکتاپ را توضیح می‌دهد، و [برنامهٔ اندروید](./manuals/android/) برنامهٔ گوشی را.

Veilway ترافیک را ناشناس نمی‌کند. شبکه‌ای که با دقت نگاه کند هنوز می‌تواند آن را تشخیص دهد. پیش از اتکا به آن، [مدل تهدید](./security/threat-model/) را بخوانید.

## این مستندات چگونه سازمان‌دهی شده است

- **شروع به کار** و **راهنماها** برای اپراتورها و کاربران هستند: نصب، اجرا و استفاده از نرم‌افزار.
- **مشخصات پروتکل** قالب‌های سیمی و طرز کار ترنسپورت‌ها را توضیح می‌دهد.
- **مرجع پیکربندی** و **مرجع API کنترل** فایل پیکربندی نود و API کنترل آن را توضیح می‌دهند.
- **راهنمای SDK** کتابخانه‌های Rust و TypeScript را پوشش می‌دهد.
- **امنیت** مدل تهدید و وضعیت لایهٔ مبهم‌سازی را دارد.

صفحه‌های فارسی همان چیزهای صفحه‌های انگلیسی را می‌گویند، جز صفحه‌های پروتکل که هنوز در فارسی خالی هستند.

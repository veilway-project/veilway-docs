این صفحه فعلا خالی است. متن زیر می‌گوید چه چیزی قرار است در آن نوشته شود.
:::

Veilway قرار است یک پلتفرم پروکسی و VPN باشد: یک هسته و SDK به زبان Rust، یک پنل وب برای اپراتورها و کلاینت‌های رسمی. هیچ‌کدام از این بخش‌ها هنوز منتشر نشده است. پنل ساخته شده است و [راهنمای نصب](./getting-started/) و [راهنمای پنل](./manuals/panel/) آن را توضیح می‌دهند. برنامهٔ دسکتاپ برای لینوکس، ویندوز و macOS ساخته شده است و [راهنمای کلاینت](./manuals/client/) آن را توضیح می‌دهد. نه پنل و نه برنامهٔ دسکتاپ از ابتدا تا انتها آزمایش نشده‌اند، و برنامهٔ دسکتاپ هنوز روی یک رایانهٔ واقعی اجرا نشده است. برنامهٔ اندروید در حال ساخت است. قدم بعدی اولین نسخه است، یعنی `v0.1.0-alpha`، و بعد از آن بررسی آن نسخهٔ آزمایشی روی یک سرور تازه. مدل تهدید و راهنماهای SDK هنوز خالی هستند.

این صفحه توضیح خواهد داد:

- Veilway چیست و برای چه کسانی ساخته شده است
- بخش‌های اصلی (هسته، پنل، کلاینت‌ها) و ارتباط آن‌ها با هم
- کدام قابلیت‌ها امروز وجود دارند و کدام فقط برنامه‌ریزی شده‌اند
- بقیه مستندات چگونه سازمان‌دهی شده است

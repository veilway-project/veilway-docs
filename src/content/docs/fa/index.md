Veilway یک پلتفرم پروکسی و VPN است برای شبکه‌هایی که اینترنت را مسدود یا کنترل می‌کنند. سه بخش دارد:

- **نود**، برنامه‌ای Rust روی سرور شما. اتصال دستگاه‌ها را می‌پذیرد، قواعد مسیریابی شما را اعمال می‌کند و ترافیک را از خروجی‌هایتان بیرون می‌فرستد.
- **پنل**، صفحهٔ وب اپراتور برای کاربران، ورودی‌ها، خروجی‌ها، مسیریابی و اشتراک‌ها.
- **کلاینت‌ها**، یک برنامهٔ دسکتاپ برای لینوکس، macOS و ویندوز، و یک برنامهٔ اندروید.

نسخهٔ فعلی آلفای `v0.3.2-alpha` است. نرم‌افزارهای دیگر می‌توانند از نود به‌عنوان پراکسی SOCKS5 یا HTTP استفاده کنند، با ورود جدا برای هر کاربر. قاعده‌های مسیریابی می‌توانند بر پایهٔ ترنسپورتی که کاربر با آن آمده انتخاب کنند. تازه‌های v0.2.0: HTTP/2 روی ترنسپورت‌های جریانی، تونل از راه پیوند نودها، بسته‌های آفلاین، پیوندهای Xray در برنامهٔ دسکتاپ، رله برای هر کاربر و هر گروه، و حالت سایت قرضی (آلفا، به‌طور پیش‌فرض خاموش).

- [نسخهٔ آلفا](./alpha/) می‌گوید چه چیزهایی دارد، هر بخش کجاست و محدودیت‌های شناخته‌شده چیست.
- [راهنمای نصب](./getting-started/) نود و پنل را توضیح می‌دهد.
- [راهنمای کلاینت](./manuals/client/) برنامهٔ دسکتاپ را توضیح می‌دهد.
- [برنامهٔ اندروید](./manuals/android/) برنامهٔ گوشی را توضیح می‌دهد.

Veilway ترافیک را نامرئی نمی‌کند. شبکه‌ای که دقیق نگاه کند هنوز می‌تواند آن را تشخیص دهد. اول [مدل تهدید](./security/threat-model/) را بخوانید.

## این مستندات چگونه سازمان‌دهی شده است

- **شروع به کار** و **راهنماها** نصب، اجرا و استفاده از نرم‌افزار را توضیح می‌دهند.
- **مشخصات پروتکل** قالب‌های سیمی و ترنسپورت‌ها را توضیح می‌دهد.
- **مرجع پیکربندی** و **مرجع API کنترل** فایل پیکربندی نود و API کنترل آن را توضیح می‌دهند.
- **راهنمای SDK** کتابخانه‌های Rust و TypeScript را پوشش می‌دهد.
- **امنیت** مدل تهدید و وضعیت لایهٔ مبهم‌سازی را دارد.

صفحه‌های فارسی مثل انگلیسی‌اند، جز صفحه‌های پروتکل که در فارسی هنوز خالی‌اند.

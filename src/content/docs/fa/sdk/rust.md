---
title: SDK برای Rust
description: ساختن کلاینت یا سرور سفارشی با crateهای Rust پروژه Veilway.
---

:::caution[هنوز نوشته نشده است]
این صفحه فعلا خالی است. SDK هنوز crate منتشرشده یا API پایدار ندارد.
:::

این صفحه این موارد را پوشش خواهد داد:

- SDK از کدام crateها تشکیل شده و هر کدام چه کاری می‌کند
- اضافه کردن آن‌ها به یک پروژه
- یک کلاینت سفارشی حداقلی
- یک سرور سفارشی حداقلی
- پایداری API و نسخه‌بندی

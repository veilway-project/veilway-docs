Veilway is being built as a proxy and VPN platform: a Rust core and SDK, a web panel for operators, and first-party clients. None of these parts is released yet. The panel is built in the code, and the [install guide](./getting-started/) and [panel manual](./manuals/panel/) describe it. The Windows and macOS client layers exist, but neither has run on a real machine yet. The desktop and Android apps are being built for the first alpha. Most of this site is still placeholders.

This page will explain:

- what Veilway is and who it is for
- the main parts (core, panel, clients) and how they fit together
- which features exist today and which are only planned
- how the rest of the documentation is organized

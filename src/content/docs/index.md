Veilway is being built as a proxy and VPN platform: a Rust core and SDK, a web panel for operators, and first-party clients. None of these parts is released yet. A Windows desktop client exists in the current code. The panel, the cross-platform clients, the Android client and the new transports are not built yet. Most of this site is still placeholders.

This page will explain:

- what Veilway is and who it is for
- the main parts (core, panel, clients) and how they fit together
- which features exist today and which are only planned
- how the rest of the documentation is organized

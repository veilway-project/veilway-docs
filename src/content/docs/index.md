Veilway is being built as a proxy and VPN platform: a Rust core and SDK, a web panel for operators, and first-party clients. None of these parts is released yet. The panel is built, and the [install guide](./getting-started/) and [panel manual](./manuals/panel/) describe it. The desktop app is built for Linux, Windows and macOS, and the [client manual](./manuals/client/) describes it. Neither the panel nor the desktop app has been tested end to end, and the desktop app has not run on a real machine yet. The Android app is being built. The next step is the first release, `v0.1.0-alpha`, followed by a check of that alpha on a fresh server. The threat model and the SDK guides are still placeholders.

This page will explain:

- what Veilway is and who it is for
- the main parts (core, panel, clients) and how they fit together
- which features exist today and which are only planned
- how the rest of the documentation is organized
